## System Architecture (5 Layers)
Layer 1 - Data Ingestion: Apache Kafka (10 Gbps)
Layer 2 - Feature Engineering: Apache Flink (80+ flow features)
Layer 3 - Multi-Model AI Detection: Transformer | CNN-BiLSTM | GNN+GAT | Autoencoder | SDN-GBM | LogBERT
Layer 4 - XAI & Alert Management: SHAP + SOC Dashboard
Layer 5 - Adaptive Response & Threat Intel: DRL AIRS + STIX/TAXII
