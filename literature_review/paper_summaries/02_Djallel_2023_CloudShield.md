# [2] CloudShield: Real-Time Hybrid Deep Learning Framework for Cloud Threat Detection
**Authors:** H. Djallel, N. Mejia, T. Chaari, A. Khiat (IEEE Access, 2023)
- **Architecture**: 1D CNN + Bidirectional LSTM over Apache Kafka deployed on Kubernetes.
- **Results**: 99.1% on CSE-CIC-IDS2018 at 3.2ms latency, 96.3% on live AWS traffic at 10 Gbps.
- **Project Role**: Real-time streaming detection pipeline in Layer 3.
