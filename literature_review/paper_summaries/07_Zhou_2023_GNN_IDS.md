# [7] GNN-Based Network Intrusion Detection System Using Traffic Flow Graphs
**Authors:** Q. Zhou, R. Shi, R. Meng, S. Wang, P. S. Yu (IEEE TIFS, 2023)
- **Architecture**: Dynamic Graph Neural Network with Graph Attention (GAT) layers.
- **Results**: 97.8% APT detection rate with 2.1% FPR.
- **Project Role**: Multi-hop lateral movement detector in Layer 3.
