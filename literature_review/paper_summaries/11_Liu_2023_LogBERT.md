# [11] BERT-Based Log Anomaly Detection for Cloud Security Event Analysis
**Authors:** Y. Liu, M. Zhang, J. Sun, L. Ma, Z. Liu (IEEE T-Reliability, 2023)
- **Architecture**: Drain3 log template parser + fine-tuned BERT masked language model.
- **Results**: 91.4% precision on AWS CloudTrail audit logs.
- **Project Role**: Control-plane audit log analyzer in Layer 3.
